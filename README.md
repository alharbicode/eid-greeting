# Eid Greeting

An Arabic, right-to-left web greeting experience for Eid al-Adha. Visitors can enter a name and open a personalized digital greeting.

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a modern web browser. No build step or server is required.

## Main files

- `index.html` — page structure and sharing metadata
- `style.css` — visual design and responsive layout
- `main.js` — greeting interaction
- `eid-preview.png` — social sharing preview
